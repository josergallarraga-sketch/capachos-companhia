# Capachos & Companhia — novo site (protótipo funcional)

Arquivos:
- `index.html` — estrutura completa da página
- `style.css` — visual responsivo
- `script.js` — catálogo, filtros, busca, quiz e formulário que prepara mensagem para WhatsApp

## Como abrir
Abra `index.html` no navegador.

## Antes de publicar
1. Substitua `whatsappNumber` em `script.js` pelo número comercial real no formato DDI + DDD + número.
2. Troque os blocos de portfólio por fotos reais dos trabalhos.
3. Revise/valide todas as especificações técnicas diretamente com a empresa.
4. Se quiser receber formulários por e-mail/CRM em vez de abrir WhatsApp, conecte o formulário a um backend ou serviço de formulários.
5. Configure domínio, favicon, analytics e SEO técnico no servidor.

O conteúdo do protótipo foi estruturado a partir das informações públicas analisadas no site atual, mas as informações técnicas e comerciais devem ser validadas antes da publicação.
